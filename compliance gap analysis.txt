  Summary

  The biggest structural difference is that the documented pipeline uses an async queue + persistent SDK agent conversation, while the C# implementation does synchronous storage + optional fire-and-forget LLM
  enrichment. The top-priority gaps for compliance are:

  1. No deduplication — duplicate observations can be stored
  2. No privacy/tag handling — <private> tags pass through unfiltered
  3. SSE broadcast never fires — Viewer UI won't get live updates
  4. Missing schema columns — content_hash, agent_type, agent_id, generated_by_model
  5. No queue — if the async LLM enrichment is meant to update stored observations, the current fire-and-forget path silently drops the result (line 143: // Could update the stored observation here in the
  future)
